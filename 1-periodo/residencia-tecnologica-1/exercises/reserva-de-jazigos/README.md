#  Reserva de Jazigos

# VISÃO GERAL

Sistema em **Linguagem C** para gerenciamento de clientes e controle de jazigos em cemintérios. Desenvolvido para funcionários administradores de espaços funerários.

# OBJETIVOS

- **Gerenciar** clientes e responsáveis;
- **Controlar** disponobilidade, reserva e ocupação de jazigos;
- **Organizar** dados cadastrais estruturados.
